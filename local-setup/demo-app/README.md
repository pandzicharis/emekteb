# Demo App Setup

Ova skripta pokreće setup za DEMO verziju aplikacije sa kompletnim demo podacima.

## Šta ova skripta radi:

1. **Truncate baze** - Briše sve postojeće podatke iz baze
2. **Osnovni seed** - Pokreće osnovni seed (admin, muallim, razredi, osnovne lekcije)
3. **Demo seed** - Pokreće demo seed sa:
   - Nastavnim planom sa 9 razreda
   - 90 učenika iz CSV fajla
   - Nastavnom godinom (1.12.2025 - 1.2.2026)
   - Grupama i rasporedom
   - Časovima, prisustvom i ocjenama za sve subote i nedjelje do današnjeg dana
   - Podacima za Školu Hifza

## Kako koristiti:

### Mac:
Dvokliknite na `demo-app-mac.command` fajl

### Windows:
Dvokliknite na `demo-app-windows.bat` fajl

## Napomena:

Ova skripta će obrisati sve postojeće podatke u bazi prije kreiranja demo podataka!
